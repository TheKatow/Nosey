# Nosey
application de curiosités rares

Les référentiels de sources et de catégories sont actualisés chaque semaine par
le workflow GitHub Actions « Actualiser les sources et catégories fiables ».
Les nouveaux domaines proviennent d'une liste maintenue de références reconnues ;
les nouvelles catégories sont extraites des fiches qui citent déjà une source
de cette liste. Le workflow peut aussi être lancé manuellement depuis l'onglet
Actions.
